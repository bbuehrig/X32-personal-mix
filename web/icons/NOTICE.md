# X32 channel icons

PNG icons `1.png`–`74.png` are derived from the BMP set in
[mamarguerat/behringer-icons](https://github.com/mamarguerat/behringer-icons)
(originally provided by Patrick-Gilles Maillot / x32ram.com).

Licensed under the GNU GPL v3 (see `LICENSE` in this directory).

Converted to transparent PNG for the web UI (light desk artwork on black →
**white** ink on transparent, so the UI needs no CSS `filter: invert`).
